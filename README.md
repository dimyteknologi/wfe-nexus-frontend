
# WFE Nexus Decision Support System

The Water-Food-Energy (WFE) Nexus Decision Support System is a web-based dashboard designed to help policymakers and stakeholders visualize and simulate the interconnections between water, food, and energy sectors.

## Features

- **Interactive Dashboard**: Visualize key metrics and trends.
- **Simulation Tools**: Run scenarios to see the impact of policy changes.
- **Data Input Forms**: Configure site-specific and context-specific parameters.
- **Admin Panel**: Manage users, roles, and system settings.

## Getting Started

1.  **Install dependencies**:
    ```bash
    npm install
    # or
    yarn install
    ```

2.  **Run the development server**:
    ```bash
    npm run dev
    # or
    yarn dev
    ```

3.  **Open the application**:
    Navigate to [http://localhost:3000](http://localhost:3000) in your browser.

## Tech Stack

- **Framework**: Next.js 15
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **State Management**: Redux Toolkit
- **Charts**: ApexCharts
- **Authentication**: NextAuth.js
